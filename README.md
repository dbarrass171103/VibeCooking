# VibeCooking

VibeCooking is an AI-powered recipe generation application currently being developed to help users create meals using ingredients they already have at home. The project combines ingredient management, AI-assisted recipe generation, live recipe editing, and recipe saving into a single interactive cooking experience.

The goal of the application is to simplify meal planning, reduce food waste, and provide a more flexible and personalised alternative to traditional recipe apps.

## Current Development Focus

The application is currently focused on:

* Ingredient management
* AI recipe generation
* Interactive recipe editing
* Mobile-first UI/UX design
* Real-time recipe customisation

Additional systems and features are still in active development.

## Planned Features

### Ingredient Management

The application is intended to allow users to:

* Add and manage ingredients currently available at home
* Quickly select common ingredients using buttons
* Manage pantry staples such as spices separately from tracked ingredients
* Use a lightweight ingredient system designed to feel closer to a shopping list than a traditional inventory system

### AI Recipe Generation

Users will be able to generate recipes based on:

* Available ingredients
* Cuisine type
* Dietary requirements
* Difficulty
* Cooking time
* Meal type
* Serving size

The AI generation system is planned to provide multiple recipe suggestions containing:

* Recipe title
* Description
* Difficulty
* Estimated cook time
* Ingredient list

### Interactive Recipe Editing

The project is being designed around a live AI cooking assistant that will allow users to:

* Request ingredient substitutions
* Adjust serving sizes
* Simplify cooking steps
* Modify recipes for dietary requirements
* Ask cooking-related questions
* Adapt recipes for alternative cooking methods

Recipe data will update live alongside the AI chat interface.

## Tech Stack

Current technologies used/planned:

* .NET MAUI

* MudBlazor
* C#
* Azure OpenAI API

## Disclaimer

AI-assisted tools were used during development primarily to support frontend styling and UI iteration. The primary focus of the project is the design, implementation, and integration of the application’s functionality, architecture, and user experience.
